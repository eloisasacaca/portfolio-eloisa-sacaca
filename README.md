# Eloisa Sacaca — Tecnologia com raízes

Portfólio pessoal de Eloisa Sacaca: projetos de tecnologia, trajetória cultural, fotos, vídeos, composições e contatos.

Este projeto possui repositório próprio e funciona de forma independente do Projeto Sorteador. O Sorteador aparece apenas como um dos trabalhos apresentados.

## Versões

- `index.html`: versão estática completa, que pode ser aberta em um navegador ou hospedada no GitHub Pages.
- `assets/`: logos fornecidas pela usuária, preservadas em arquivos SVG que contêm as imagens originais.
- `floot/pages/_index.tsx`: versão React utilizada na hospedagem do Floot.

As alterações no GitHub não são publicadas automaticamente no Floot. Para atualizar o site hospedado, publique a versão correspondente no projeto Floot.

## Visualizar a versão estática

Abra `index.html` em um navegador. A pasta `assets` deve permanecer ao lado do arquivo.

## GitHub Pages

Se desejar hospedar a versão estática pelo GitHub Pages, selecione Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Conteúdo

Fotos, vídeos e links culturais selecionados do portfólio da usuária no Canva. Logos do Marabaixo do Arthur Sacaca e da Associação Cultural Devotos de São José enviadas pela usuária.

Nenhuma informação interna de pacientes ou colaboradores é utilizada.
